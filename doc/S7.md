## 发现的问题与修复依据

外部文件可以用字符引用表示回车，例如 `<text ...>A&#13;B</text>`。原实现能正确读成 `A\rB`，但序列化时把它写成字面回车，下一次解析时会得到 `A\nB`；CRLF 也会丢失其中的 CR。

先加入三个回归用例，旧实现的定向检查为 **94 通过、3 失败**，均在第一次保存读回后发现文本不一致。修复继续使用 XMLSerializer 完成合法性校验和转义，再将输出中实际的 CR 写为 `&#13;`。没有提前替换输入文本，因此字面量字符串 `&#13;` 仍按普通文字转义，不会被误读成回车。随后补充该区别的对照测试和一条经过 CLI 的 read/save/read 场景。

三种特殊文本分别连续保存读回三次，文本与初始值完全相同。现有中文、表情、`&`、尖括号、引号以及非法 XML 字符拒绝测试也继续通过。

## 重构与依赖检查

1. MoveCommand 和 ScaleCommand 原先重复执行状态、递归快照和撤销逻辑。提取 GeometryCommand 后，各具体命令只保留参数和对 Shape 的 move/scale 调用；准备及变换成功后才保存快照，继续使用精确旧值撤销。既有 117 个几何安全测试和新增命令生命周期测试均通过。
2. CommandRegistry 的构造函数拆为四个注册方法，保留原顺序、帮助内容和统一 WeakMap 反馈。注册表仍负责命令接线，未另外引入命令插件系统。其余较大的 Document、ShapeFactory 的职责集中，暂不继续拆分。
3. StatefulCommand、DomainError、CommandStateError、HistoryError 原位置不符合“类名与文件名一致”，HistoryError 还与 CommandHistory 同文件。本次分别归位，并保留旧导入路径的重导出。
4. GroupCommand/AddToCommand 使用 Shape 已提供的 `containsDescendant`，去掉调用它之前多余的 Group 判断。剩余的 `instanceof Group` 用于容器资格校验或导入时挂载子节点，不是按六类图形逐一分派操作；叶子操作走多态，显示走 Visitor。

实际依赖规则如下，CLI 为接线层，可以构造命令并读取领域公共接口；基础设施仅依赖应用层的 ports。

| 源模块 | 允许依赖 |
|---|---|
| domain | domain |
| commands | commands、domain |
| application | application、commands、domain |
| application/ports | ports、domain |
| cli | cli、application、commands、domain |
| infrastructure | infrastructure、domain、application/ports、Node 和 XML 库 |
| main.ts | 各模块和 Node，负责装配 |

`domain/internal/treeMutation` 只允许 Document、Group、Shape 引用，不能从公共 index 重导出。AST 检查涵盖静态 import/export、类型 import、字面路径的动态 import/require，拒绝无法检查的动态路径；同时检查类文件、常见名字 switch/比较及叶子 instanceof 分支。27 个内存正反样例确认检查器能区分违规代码、合法依赖和注释/字符串。

静态规则不能证明任意别名或动态技巧下的所有代码性质，因此本次还人工复核了工厂、命令注册、SVG 编解码、Visitor 和全部现有类型判断。当前命令名字分派集中在 CommandRegistry，图形类型构造分派集中在 ShapeFactory。属性名白名单的 switch 不属于图形类型分派。

检查器使用已安装 TypeScript 7 的 AST/同步项目接口，不新增依赖；解析项目完全在内存中，不改写被检源文件。最初沿用旧版 TypeScript 的解析入口导致工具测试失败，改用项目当前接口后又通过反例发现缓存未刷新；现在每次检查失效旧快照及缓存，并在结束时关闭接口进程。这些失败发生在检查工具开发过程中，最终检查已通过。该接口标为 unstable，升级 TypeScript 后需要重新运行工具测试；当前版本由现有 package-lock 锁定。

## 2026-10-31：拒绝负尺寸、半径和描边宽度

按用户要求仅处理测试评审第一项：原领域层只检查有限数，负的宽高、半径和描边宽度仍能通过创建、属性设置或 SVG 读入进入模型。依据 [SVG 2 几何属性](https://www.w3.org/TR/SVG2/geometry.html)、[基本图形](https://www.w3.org/TR/SVG2/shapes.html) 和 [描边宽度](https://www.w3.org/TR/SVG2/painting.html#StrokeWidth)，这些负值非法；项目采用直接拒绝的策略，具体约定已补入验收规格 DATA-09。

Shape 增加共用的非负有限数校验，Document 的宽高、Rect 的宽高、Circle 的半径、Ellipse 的两个半径及全部类型的 stroke-width 统一调用。构造、属性修改和缩放结果均保持该不变量，现有工厂、CLI、SVG Reader 自动复用领域约束。零值（含数值 -0）、负坐标与负移动增量仍合法；scale 因子仍须严格为正。错误码沿用 `invalid-number`，负值输出 `error: invalid number for <属性名>: must be non-negative`。不改变文件接口和层级命令。
