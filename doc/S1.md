## 本步骤实现的功能

- CLI 启动时显示 `svg>`；
- 输入空行后继续显示提示符，不产生业务错误；
- 以 `#` 开头的行作为注释跳过；
- 未实现命令输出 `error: command not implemented: ...`，并继续等待输入；
- EOF 时正常结束 REPL；
- 建立后续步骤需要遵守的命令语法、错误前缀、状态原子性和 undo/redo 规则。

步骤一没有实现 `init`、`create`、`move`、SVG 读写或 undo/redo；这些命令当时仍处于后续步骤范围。
