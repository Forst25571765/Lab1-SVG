## 本步骤实现的功能

- 定义 Command 模式的 `execute()` 和 `undo()`；
- 用 `Document`、`Shape` 和 `Group` 作为命令接收者；
- 实现 `CreateCommand`、`DeleteCommand`、`MoveCommand`、`ScaleCommand`、`SetCommand`；
- `CommandExecutor` 只在命令执行成功后记录历史；
- undo 栈和 redo 栈支持正常转移；
- undo 后执行新编辑会清空 redo 栈；
- 删除命令可以恢复完整子树、父级和原始顺序；
- Group 的移动和缩放可以作为一个命令整体撤销；
- `set` 撤销时既能恢复旧值，也能恢复属性原本不存在的状态；
- 命令失败时不进入 undo/redo 历史。

步骤三没有实现 `GroupCommand`、`UngroupCommand`、`AddToCommand`、`FrontCommand` 或 `BackCommand`，这些属于步骤四的层级操作。
