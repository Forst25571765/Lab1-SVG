## 文档操作与路径策略

| 操作 | 行为 | 历史 |
|---|---|---|
| `init()` / `init(w,h)` | 默认 800×600 或指定尺寸；替换当前文档，清除读入路径 | 成功后清栈并禁用 |
| `read(path)` | 读文件，完整解析和验证临时文档后才替换当前文档并记录路径 | 成功后清栈并禁用 |
| `save(path)` | 写出到显式路径，不改变最近一次 read 的路径 | 写盘成功后清栈并禁用 |
| `save()` | 回写最近一次成功 read 的路径 | 同上 |
| `canvas()` | 返回当前宽、高 | 查询，不改变两栈或禁用状态 |
| `canvas(w,h)` | 复用 Document 的失败原子性修改尺寸 | 成功后清栈并禁用 |

没有当前文档时，save/canvas 报 `no document. use 'init' or 'read' first`。有文档但没有读入路径时，无参数 save 报 `no save path. specify a file path`；不自动选择文件名。显式另存之后仍以最近成功 read 的路径为默认值，这是对原文“保存到读入时路径”的具体落实。

成功文档操作之后，undo/redo 报 `undo not allowed after io command`；下一次成功编辑解除禁用并开启新历史。查询、失败编辑或失败文档操作均不能解除禁用。原历史已清空，不能跨边界撤销。

本步骤使用同步端口，不把 Promise 传给现有 executeDocument。未来采用异步 IO 时，必须另行实现等待成功后的历史提交，不能直接替换为异步实现。

## SVG 支持范围与保真规则

- 支持六种内置类型：rect、circle、ellipse、line、text、g；支持空组和多层嵌套。
- 保存根 SVG 的命名空间、width、height 和匹配的 `viewBox="0 0 w h"`。
- 读取要求 width/height 和各类型必需几何属性显式给出；数值支持普通小数、科学计数法和 px 长度，拒绝空值、非有限数和百分比等未支持单位。
- 读取允许省略 viewBox；给出时只接受与画布对应的 `0 0 w h`。其他坐标映射尚无领域模型承载，因此明确报错。
- 保留 ID、几何、fill、stroke、stroke-width、文本、父子关系和文档顺序。未设置的可选样式不补默认值，Group 上的样式仍留在 Group 上。
- text 作为元素内容，保存/读回中文、空格、换行、引号及 XML 特殊字符；无效 XML 字符导致序列化失败，写盘和历史均不发生改变。
- `front` 位于同级列表末尾，`back` 位于开头；写出和读回均不反转顺序。
- `data-kind` 在 g 上允许降级为普通 Group，不恢复插件行为；`create box` 仍由工厂拒绝。
- transform、CSS/style、其他未知属性、未知图形、tspan 等混合子元素、DOCTYPE 和额外处理指令不在本步骤支持范围内，不能静默忽略后宣称保真。

缺失或空白 ID 按“标签名+序号”生成。读取前先保留整个文件的显式 ID，避免自动分配占用了后面才出现的 ID；各标签计数从 1 开始，按文档先序遍历确定 warning 顺序。重复显式 ID 保留领域错误 `id already exists: <id>`，不自动重命名。warning 仅随成功结果返回，失败时不会向控制台输出半完成的导入信息。

## 失败原子性与输出边界

1. 读入：文件读取、XML 解析和整个临时文档验证全部完成，才替换当前文档及路径；任一失败保留原对象、属性、层级、路径和历史。
2. 保存：序列化完成后才写文件，写入成功返回后才建立历史边界。NodeFileSystem 先写独占创建的同目录临时文件，再重命名替换目标；失败只清理自己创建的临时文件。
3. 文件异常分别转换为 `cannot read file: <path>`、`cannot write file: <path>`，保留原始 cause。格式错误使用 `invalid svg: ...`，领域错误保留原文本。
4. 应用层返回尺寸、路径、元素数、warning 等结构化结果，不直接打印。S6 负责添加统一 `error:` 前缀及 `read ... (N elements)`、`saved to ... (N elements)` 等摘要；元素数包含 g，不包含 svg 根。
